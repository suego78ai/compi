⚡ 웹 스크래핑 엔진 제어 센터

웹 브라우저 내장 스크래핑 엔진을 통해 진학사/유웨이 입시 경쟁률 데이터를 실시간 수집 및 갱신합니다.

현재 대시보드에 등록된 대학들의 경쟁률 페이지 URL을 순차적으로 실시간 웹 스크래핑하여 최신 경쟁률로 전수 갱신합니다.

엑셀 서식 파일(.xlsx)을 업로드하면 브라우저 스크래핑 엔진이 모든 행의 대학 URL을 자동으로 파싱합니다.

📊

클릭하거나 엑셀 파일(.xlsx)을 드래그 앤 드롭 하세요.

현재 수집·스크래핑된 모든 대학 데이터(학과별 모집/지원/경쟁률)를 엑셀(.xlsx) 또는 JSON 파일로 내보내어 백업하거나 저장소에 반영할 수 있습니다.
